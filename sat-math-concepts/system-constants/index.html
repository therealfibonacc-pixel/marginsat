Systems with a missing constant

Parallel and identical lines, and the sign trap in k² = something.

36practice questions
3levels

The key idea

Two lines have no solution when they are parallel (same slope, different intercept) and infinitely many when they are the same line. In coefficient form, the equations' x-, y- and constant terms must be in the same ratio for infinitely many solutions; only the x and y ratios match for none.

The trap

Solving k2= something and keeping both signs. Check each value against the constants' ratio; one sign often gives parallel lines instead.

Can Desmos do it?

A slider for k lets you watch the lines turn parallel, but reading an exact value off a slider is slow and risky. Matching ratios takes one line of algebra.

Level 1 · Warm-up

In the system below, a is a constant.
ax+7y=15 21x+21y=12 For what value of a does the system have no solution?
Show the answer
Answer: 7No solution means the lines are parallel: the x- and y-coefficients are in the same ratio, but the constants are not. The y-coefficients are in the ratio 7:21=1:3, so a=321​=7. The constants are 15 and 12, not in the ratio 1:3, so the lines don't coincide.

Level 2 · Test level

In the system below, k is a constant.
kx+4y=24 9x+ky=36 For what value of k does the system have infinitely many solutions?
Show the answer
Answer: 6Infinitely many solutions needs all three ratios equal: 9k​=k4​=3624​. From the first two, k2=36, so k=±6. The constants' ratio is 3624​=32​, which matches 9k​ only when k=6. With k=−6, the lines are parallel and there is no solution.

Level 3 · Beyond the test

In the system below, a and b are constants and a>0.
ax+2y=25 15x+(a+1)y=b If the system has infinitely many solutions, what is the value of a+b?
Show the answer
Answer: 80The equations must be multiples of each other: 15a​=a+12​=b25​. From the first two, a(a+1)=30, so a=5 (the other root is negative). Then b25​=155​, so b=75, and a+b=80.
